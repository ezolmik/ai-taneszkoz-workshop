A saját ötleteidé a terep

Három kis kör. Mindegyik végén megállhatsz egy működő eredménnyel.

1 Legyen saját oldalad!

  1. Jelentkezz be a GitHubra, és készíts másolatot a workshop repójáról a Fork gombbal.
  2. Nyisd meg: Settings → Pages.
    • Válaszd a Deploy from a branch lehetőséget.
    • Válaszd a main ágat és a /(root) mappát.
  3. Kattints a Save gombra.
  4. A publikálás befejeztével nyisd meg az új oldalad itt megjelenő webcímét!

✓ Ezzel lett egy új publikus weboldalad.

2 Változtass meg egy apróságot!

  1. A saját repódban nyisd meg a peldak/parosito/index.html fájlt.
  2. Kattints a ceruzára, és a szópárok listájában írd át a garden szót bear-re, a hozzá tartozó kert szót pedig medve-re.
  3. A Commit changes gombbal mentsd el a módosítást.
  4. Várd meg a deploymentet, majd frissítsd a saját oldaladon a játékot!

✓ Megjelent a saját változtatásod.

Ehhez még AI sem kell — egy böngészőből, akár tabletről is megy.

3 Valósítsd meg a saját ötletedet!

  1. Válassz egy példát, és írd át a generáló promptját a saját ötletedre.
  2. Add be az AI-nak, és mentsd el a generált kódot az index.html fájlba.
  3. A saját repódban a kiválasztott játékban cseréld le az index.html fájl tartalmát az új kódra.
  4. A Commit changes gombbal mentsd el a változtatásokat.
  5. Várd meg a deploymentet, majd frissítsd a saját oldaladon a játékot!

✓ A saját pedagógiai ötletedből taneszköz lett.
